# 図の設計と来歴確認

## 適用範囲

review（図の提案） / 手動の成果物作成。分野に依存しないAgent手順として利用する。
実行前に[入出力と判断例](references/contract.md)を読み、現在の作業票の契約を優先する。

## 手順

1. まず図で答える問いを決め、比較なら同じ尺度、推移なら順序付き系列、分布ならseed別原値を使用する。
2. 入力のパス・ハッシュ、実験ID、コード版、集計方法、ラベルと単位を図の仕様に記録する。推測値や架空の結果で図を埋めない。
3. Agent作業票では図の案と必要入力をinterpretationまたはnext_questionsへ返す。回答JSONのみという契約を守り、画像や追加ファイルを直接書かない。
4. 利用者が別途図作成を依頼した場合だけ、提供された実測入力から図を作る。使用したコード・入力ハッシュ・生成条件をサイドカーへ記録し、既存の研究成果物を上書きしない。
5. 生成後にフォント、ラベルの重なり、軸の切断、尺度、凡例、本文との数値一致を目視・再計算で確認する。未確認なら確認済みとしない。

## 制約

元のGAログパーサ・3D描画ライブラリは移植しない。自動図生成、図の配布、来歴のランタイムゲートは未実装。
研究データ、実験番号、非公開リポジトリ、元研究固有の定数やコードに依存しない。
未実行・対象なし・必要入力欠落をPASSにしない。状態DBと既存成果物を直接編集しない。
