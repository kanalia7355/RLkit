# multi-exp-comparator

lab_exの同名スキルの観点を汎用契約へ再実装したもの。元スクリプトの完全移植ではない。

COMPARISON.mdで実験別の指標・方向・改善幅・件数を確認する。異なるデータ・単位・対照・予算を同一ランキングに混ぜない。比較可能性を確認してから解釈する。失敗結果も除外せず表示する。

報告・不具合・改善候補の既定保存先は研究フォルダ内のMarkdown。外部投稿は行わない。
