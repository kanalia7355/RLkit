# 報告会用Markdownの契約

読み手は研究の背景を完全には知らない指導者・共同研究者を想定する。
報告対象は一つのサイクル。過去結果に触れる場合はサイクル番号と比較条件を明示する。

1. 要旨: 何を調べ、何を測定し、何が分かり、何が未解決か。
2. 背景・目的: 関心の理由と研究上の問い。先行研究の申告を確認済み事実に変えない。
3. 方法: 仮説、対照/介入、変更点、固定条件、データ、seed、指標の単位・方向、採用基準。
4. 結果: 失敗を含めた実測表。件数、効果の向き、閾値到達と統計検定の有無。
5. 考察・限界: 観測と解釈を区別し、交絡、標本数、一般化の限界を記す。
6. 結論・次の方針: 支持/未支持/無効を明示し、次の検証や停止の理由を示す。
7. 相談事項: 方針判断が必要な点。不明な相談内容を事実として作らない。
8. 参考資料・証跡: 実測、事前登録、コード、ログへのローカル参照。外部資料の未調査を明記する。

表の値は保存済み数値から生成し、主張の強さを検定未実施の設計に合わせる。
既定出力はreports/MEETING_REPORT-NNN.md。研究名、サイクル、採用方針ハッシュを明示する。
