# 研究報告書

報告会・指導相談で研究の判断を共有する際に使う。週次スケジュールには依存しない。
背景、問い、方法、結果、考察、結論、次の方針、相談事項、出典を一つの報告書にする。
実験後はreviewの解釈と限界を整え、ランタイムがMEETING_REPORT-NNN.mdに実測表と根拠を併記する。
提出先に合わせた追加編集も、元の数値・失敗・不確実性・出典を保ってMarkdownに保存する。

作成時は[構成と根拠の契約](references/report-structure.md)を読む。
レビューに書く数値はmetricsと照合する。図が必要なら元データと生成条件を添える。
論文やURLが未確認なら参考文献として読了済みに扱わない。ユーザー申告資料と検証済み実測を分ける。
GitHub Issue投稿、weekly運転、PDF/PPTX変換はこのスキルの既定処理に含めない。
